# External Hair Asset Notes

The app now prefers downloaded layered assets under:

```text
assets/hair/layered_downloaded/<style>/back.png
assets/hair/layered_downloaded/<style>/front.png
```

Generated comparison assets live under:

```text
assets/hair/layered_generated/<style>/back.png
assets/hair/layered_generated/<style>/front.png
```

Downloaded source PNGs are kept under:

```text
assets/hair/downloaded_sources/
```

Use the generated files as layout templates. For final artwork, replace each
`back.png` and `front.png` with transparent PNGs of the same conceptual role:

- `back.png`: hair mass that should appear behind the face.
- `front.png`: bangs, curls, or top/front details that should appear over the face.

Current downloaded source pages:

- Long hair/wig: https://www.pngplay.com/image/70612
- Straight long hair for mode 2: https://www.pngplay.com/image/71188
- Curly texture: https://www.pngplay.com/image/572784
- Short hairpiece: https://www.pngkey.com/detail/u2e6i1u2w7u2r5o0_modern-hair-hairstyle-png-high-quality-image-mens/

Other places to search for replacement source material:

- Pixabay: https://pixabay.com/
- Wikimedia Commons: https://commons.wikimedia.org/
- OpenGameArt: https://opengameart.org/

Before using any downloaded asset, verify the specific file page:

- The file allows modification/adaptation.
- The file allows exhibition/commercial/public use if needed.
- Attribution requirements are recorded if the license requires credit.
- The asset is not merely a preview image with a different license from the download.
- The image does not contain a trademarked character, brand, or recognizable person.

For the cleanest final look, commission or draw the hair as two transparent
layers rather than relying on scraped PNG overlays. Realistic hair edges are
hard to cut out cleanly from photos, and unclear PNG sites often have weak or
ambiguous licensing.
